# The Museum of Almost

**An interactive museum for things that nearly exist.**

A playful single-page gallery of impossible objects, invented histories and tiny stories. No dependencies, build tools, images or APIs. Everything, including the illustrations, is made with HTML, CSS and JavaScript.

## The collection

- **A Pocket Moon:** A celestial body small enough to carry, still pulling the tides in your teacup.
- **Jar of Thursdays:** An archive of afternoons you wish had lasted longer.
- **The Elsewhere Door:** A portal into the life where you made a different choice.

Each exhibit reveals three original micro-stories. Explore, choose **Another possibility**, and notice the objects responding.

## Run

Open `index.html` in any modern browser. That's it.

## Design notes

A dark, editorial museum with warm ivory typography, brass accents, CSS-only artifacts, accessible buttons, a keyboard-dismissable dialog, responsive exhibit cards and motion that rewards curiosity. Written as a small experiment in storytelling through interface design.

## Deployment

Host the root `index.html` on GitHub Pages or import this repository as a static site in Vercel.
